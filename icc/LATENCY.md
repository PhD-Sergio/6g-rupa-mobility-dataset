Latency sensitivity: geometry and propagation, not packet simulation

This is an isolated shared-object clone of PLMN-GraphSim. The original checkout is unchanged. Distance capture is opt-in, uses no RNG, and observes every dispatched terrestrial cell-change event once. A run asserts CSV rows = handover_count. The hook captures the pinned PSA before the handover state machine runs. Per-event values are unscaled; national-user scaling is irrelevant to their distributions.

The matrix has 27 original national field/operator targets × 3 mobility profiles × 3 independent seeds (243 rows). These are NEW sensitivities using the September seeded simulator, not a reproduction of the original July sweep. Mobility follows original profiles: pedestrian RandomWaypoint(5,0,2), urban RandomWaypoint(50,0,20), highway GaussMarkov(120,0.85,5), 2 s checks, 1200 s duration, scale factor 1000, 1–2 sessions. A smoke run caps Portugal at 50 agents and 60 s; do not report smoke quantiles as national results. Exact seeds, input SHA-256, commit, Julia version, event count and instrumentation hash are saved per run.

No AMF or SMF positions exist in the source data. The analysis explicitly assumes both colocated at the pinned PSA. It reports separate RAN–AMF, SMF–old IUPF and SMF–target IUPF RTT terms. AMF–SMF and SMF–PSA propagation terms are zero *by this placement assumption*. These are not universal bounds on 5G. `selected5G_path_switch_ack_propagation` sums the grounded retained-context Xn branch from target RAN Path Switch Request transmission to Path Switch Ack reception (TS23.502 §4.9.1.2.2/.4; notes/5g-message-counts.md). d1 uses RAN–pinnedPSA plus pinnedPSA–oldIUPF RTT; d2 uses RAN–pinnedPSA plus pinnedPSA–targetIUPF RTT. In d2, sequential SMF–PSA modification RTT is zero solely because of assumed colocation; delayed old-IUPF deletion is excluded. Optional preliminary PSA allocation also has zero propagation under this colocation assumption, while its processing would remain. This is a selected post-Xn acknowledgement propagation component, not application interruption or full handover latency.

Geodesic distance d becomes RTT = 2*s*d/v, with v=200 km/ms (fiber), route stretch s=1,1.5,2. The s=1 case is an optimistic geometric propagation floor. Processing, queuing, retransmission, radio access, enrollment, authentication and timers are omitted. The script also reports local-attachment RTT, and peer RTT with peers placed at nearest or pinned PSA, plus an explicit two-exchange local-then-peer scenario. RUPA peer notification can be parallel across peers, but completion still depends on the slowest peer's RTT and policy; no claim of constant elapsed completion time follows from flat message depth.

Production results (2026-10-13): 243/243 runs, 189.6 M events, no failures. Summaries: `results/latency-summary-s1.csv`, `results/latency-summary-s2.csv` (from `aggregate_latency.py`). s=1, per-run medians: 5G Ack 0.42–15.71 ms (p95 ≤ 25.6 ms); d2−d1 median −3.1 to +4.0 ms; local attachment ≤ 0.21 ms (p95 ≤ 0.54 ms); peer at pinned PSA 0.21–7.85 ms, ratio to 5G d1 0.46–0.54 in every run (a consequence of the AMF/SMF-at-PSA placement). Used in paper.tex "Round trips (propagation only)".

Edge-control variant (2026-10-13): `edge5G_path_switch_ack_propagation_d1/_d2` keep AMF=SMF at the serving (old) I-UPF site, as retained on Xn. d1 = RTT(target RAN, old I-UPF site); d2 adds RTT(old site, target I-UPF) for N4 establishment and then RTT(old site, pinned PSA) for PSA modification (sequential, notes/5g-message-counts.md). AMF/SMF relocation and I-SMF insertion are ignored, which favours 5G. Results over 243 runs, s=1, per-run medians: d1 0.01–0.20 ms (0.90–0.99 × RUPA local attachment), d2 0.45–8.31 ms (p95 ≤ 13.25 ms). Implication: propagation depends on control placement, not on the architecture. Every 6G-RUPA renumbering also notifies its flow peer (0.21–7.85 ms with the peer at the anchor), so an edge-control 5G d1 move completes sooner than a RUPA move. Old addresses remain usable until confirmation, so this is completion time, not interruption. Tests 4/4.
